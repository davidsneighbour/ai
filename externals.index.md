# Externals index

This file collects notes about foreign instructions, skills, prompts, agents,
and other AI assets that I use regularly. Use it as a lightweight map to
external references that influence this repository without living inside it.

## Install externals

Run this script to install all external assets listed below:

```bash
#!/usr/bin/env bash
set -euo pipefail

npx skills add https://github.com/emilkowalski/skills --skill '*' --yes
```
